# Mohamed Gym Tracker

تطبيق ويب تقدمي (PWA) بسيط لتسجيل برنامج Upper / Lower الثابت:

- السبت: Upper A
- الأحد: Lower A
- الاثنين: راحة
- الثلاثاء: Upper B
- الأربعاء: راحة
- الخميس: Lower B
- الجمعة: راحة

## المزايا

- تسجيل الوزن والعدات لكل جولة.
- عرض آخر نتيجة لكل تمرين.
- حفظ تلقائي محليًا في المتصفح.
- مؤقت راحة.
- زر بحث يوتيوب لكل تمرين مع إمكانية وضع رابط مخصص.
- سجل للحصص السابقة.
- تقارير يومية وأسبوعية وشهرية مع مقارنة بالفترة السابقة.
- تسجيل الوزن ومحيط الخصر.
- تصدير واستيراد نسخة احتياطية.
- يعمل دون إنترنت بعد أول فتح.
- قابل للتثبيت على شاشة الهاتف.

## التشغيل محليًا

لأن Service Worker يحتاج خادمًا محليًا، لا تفتح `index.html` مباشرة بالنقر المزدوج.

استخدم مثلًا:

```bash
python -m http.server 8000
```

ثم افتح:

```text
http://localhost:8000
```

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا.
2. ارفع جميع الملفات الموجودة في هذا المجلد إلى الفرع `main`.
3. من Settings > Pages اختر:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: / (root)
4. افتح رابط GitHub Pages من هاتفك.
5. من متصفح Chrome اختر “Add to Home screen” أو “Install app”.

## ملاحظة مهمة عن البيانات

النسخة الحالية لا تستخدم تسجيل دخول أو قاعدة بيانات. البيانات محفوظة في `localStorage` على نفس الجهاز والمتصفح. استخدم زر تصدير نسخة احتياطية دوريًا.
